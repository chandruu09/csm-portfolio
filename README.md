## 🚀 About the Project

This portfolio website is designed to showcase my technical skills, projects, educational background and professional journey. It features a clean, modern black-and-white design, interactive animations and a 3D visual element built using Three.js.

## ✨ Features

- Modern and minimal UI design
- Interactive 3D animated sphere using Three.js
- Responsive design for desktop and mobile devices
- About Me section
- Technical Skills section
- Projects showcase with GitHub links
- Experience and Certifications section
- Contact form
- Resume download functionality
